## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> POST SelectGroup | the chosen board id and return URL cross from the client to the server |
| non-member and nonexistent-board responses | two bodies an attacker could compare to learn board membership |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-96-12 | Tampering | SelectGroup POST (cross-site request) | high | mitigate | every row's form keeps `@Html.AntiForgeryToken()`; the controller's antiforgery validation and membership check are unchanged; the button is only a submit control |
| T-96-13 | Information disclosure | picker markup used as a membership oracle | high | mitigate | hidden inputs byte for byte as today and `returnUrl` echoed nowhere else, so CrossBoardPickerSkipTests' normalised-body comparison still proves identical responses; the guard fact pins exactly one `name="returnUrl"` and no `formaction` or `data-return-url` |
| T-96-14 | Tampering | open redirect via returnUrl | medium | mitigate | the hidden input value and the controller's local-URL check are unchanged; no new place renders the value |
</threat_model>
