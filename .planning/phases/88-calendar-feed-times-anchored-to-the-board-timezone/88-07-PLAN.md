<recorded_choices>
**A board rename raises every event and quest on the board, including rows outside the feed window and cancelled ones.**

Renames are rare, done by a SuperAdmin from the Platform area. Raising a row the feed does not currently carry is harmless: its number simply rises. Filtering to the window would pull the window's configuration into the Repository layer for no correctness gain.

The load needs `IgnoreQueryFilters()`, because the Platform rename runs with no active board, or with a different one, and every ambient filter then fails closed to zero rows. It is re-narrowed at once to the renamed board ids. That keeps it strictly narrower than any single board's ambient filter, the same argument the five existing allowlisted call sites make.
</recorded_choices>
