## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Line-ending damage from shell edits | Three times this session an executor or fixer used `sed -i` or a Python rewrite on a C# test file. That stripped CR or turned `\r\n` string literals into real line breaks, which broke the build. It was caught before commit every time. The feed tests pin exact CRLF bytes, so this recurs on exactly the files the gap fix must touch. | advisory | Tell every executor to edit C# files with the Edit tool only, never `sed -i` or Python rewrites. Before each commit, check that `git diff --stat` shows only the intended line counts, not a whole-file rewrite. |
| Pre-authorizing requirement marking | The orchestrator told 88-04 its requirements step would close CALTZ-09, and the executor marked a manual, unperformed production check Complete. It was reverted in `eb7c553c`. | advisory | Never tell an executor to mark a manual-only requirement. Mark requirements only after the evidence exists (UAT pass). |
| Harness worktrees fork from origin/main | Claude Code's `isolation="worktree"` forks from `origin/HEAD` (main), not the milestone branch HEAD, so executors would miss unpushed work. | advisory | For parallel waves, create worktrees from HEAD with `gsd_run query worktree.create`, dispatch without `isolation`, and merge with `worktree.cleanup-wave` (see memory `feedback-parallel-waves-head-worktrees`). |
| Stale isolation sentinel | After about 30 minutes, `.gsd/dispatch-isolation-sentinel.json` goes stale and the Agent guard hook demands `isolation="worktree"` on a sequential dispatch. | advisory | Re-run `gsd_run query dispatch-isolation --raw --phase 88 --force-isolation none` right before any late sequential executor dispatch. |
| cleanup-wave blocks renames | `worktree.cleanup-wave` blocks a branch with a file rename as `branch_contains_deletions` unless the manifest entry carries `declared_deletions`. | advisory | Declare the planned deletion or rename in the manifest entry before merging. |
