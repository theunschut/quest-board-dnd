boards, and the gated test only ever uses its own scratch database. On Linux the app needs SQL auth through

mode, not a Kerberos problem. Never set `DOTNET_GCHeapHardLimit`.

its single save (precedent: `EventSeriesRepository.CreateWithOccurrencesAsync`), so the single-save unit fact still
holds. Any other gated failure (FK conflict, rollback not complete) is also a gap with its error text attached.
