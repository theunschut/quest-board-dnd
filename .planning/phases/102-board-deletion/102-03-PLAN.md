<objective>
Add a display-only board-count column to `/platform/Users` so a super admin can see who is still linked where while
emptying a board before deleting it (D-12, D-13). Task 1 is a vertical slice: one grouped query, service, view model,
controller and the desktop column, proven over HTTP. Task 2 brings the phone twin and its sheet.

Discretion resolved here: the user-to-board-names lookup lives on the user side (`IUserRepository`/`IUserService`),
not on `IGroupService` as research sketched. `UsersController` already injects `IUserService`, so its constructor does
not change, and this plan shares no file with the board-delete plans, so it runs in parallel with them. `UserGroups`
and `Groups` carry no query filter, so the query needs no filter bypass.

Output: `GetBoardNamesByUserAsync` end to end, the desktop column, the phone details and its sheet, tests.
</objective>
