<objective>
Extend the tracer's delete (plan 102-01) from the quest family to every board-owned table and the three cross-board
reach-ins, and prove it on InMemory with a model-driven foreign-key sweep, because InMemory enforces no foreign key
and runs no cascade (the reason the original bug shipped). Task 1 adds the per-kind removed counts and builds the
test graph and the sweep against the existing quest-family delete. Task 2 completes the delete for every remaining
table and the unlinks.

Decisions implemented: D-01, D-02, D-03, D-04, D-05, D-06, plus the D-09 recheck and D-11 single-save facts.
Discretion resolved here: images are database blobs that cascade from their parent, so there is no file cleanup and
no image row is loaded.
Output: `BoardContentKind`, `BoardDeletionResult.RemovedCounts`, the full repository delete, the test graph and
the behaviour suite.
</objective>
