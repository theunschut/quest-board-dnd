<objective>
Prove the cross-board read is bounded, and prove it actually crosses boards.

This application has shipped two real cross-tenant leaks and had a third live gap found during a
later discussion, which is why this suite is mandated rather than left to judgement (D-17). It
has four required cases, and the second one is the one that proves the feature works: a suite
built only from the sibling board-scoped isolation test would stay entirely green if this page
silently collapsed to a single board — breaking the whole feature while proving perfect
isolation. Absence testing proves safety; only the two-joined-boards case proves the thing works.

That case must therefore be its own fact, seeded across three boards with the viewer in two of
them, and must never be folded into the "non-member board is absent" fact.

Purpose: the phase's proof obligation.
Output: one isolation suite, the filter behaviour facts, and the recorded static audit.
</objective>
