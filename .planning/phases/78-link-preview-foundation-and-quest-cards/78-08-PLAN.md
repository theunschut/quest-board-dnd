<objective>
Put the Copy shareable link control on the quest page, on both platforms, as one reusable partial with the signed URL minted at render time.

This is the deliberate act that turns an ordinary quest URL into a shareable card. An unminted URL still leaks nothing; only a link a member consciously copied carries a signature. The control is intentionally quiet — a secondary button in the summary surface — because it is a utility action, not the page's purpose.

Purpose: make sharing a deliberate, one-click act, and warn about its permanence before the link leaves the page.
Output: a shared partial, one delegated click handler, the render-time mint, both host views, and an end-to-end test proving the embedded URL really resolves.

Decisions implemented (see 78-CONTEXT.md): D-15, D-16
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated member → minted token | A board member causes a permanent bearer link for a quest's card metadata to come into existence |
| page source → link recipient | The minted URL sits in the rendered HTML and travels wherever the member pastes it |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-78-21 | Information Disclosure | signed URL embedded in page source | low | accept | The URL is visible only to callers already authorised to view that quest page, which is exactly the set permitted to mint it. The page requires a login and is board-scoped, so page-source visibility grants nothing the viewer did not already have |
| T-78-02 | Spoofing / Elevation of Privilege | board id used when minting | high | mitigate | The token carries the quest's own board id, taken from the loaded quest rather than from the viewer's session, so the token describes the resource and not the viewer |
| T-78-07 | Repudiation | permanence of an issued link | medium | mitigate | An always-visible note states before any copy that the link cannot be revoked and that deleting the quest is the only retraction. The warning is placed where it is seen before the link is pasted, not inside a transient confirmation that can be missed |
| T-78-22 | Elevation of Privilege | who may mint | low | accept | Any board member may mint. A quest is board-level information, the page is already login-gated and board-scoped, and anyone who can read the page can reproduce its contents by hand, so a role gate would add an authorization branch that protects nothing |
| T-78-23 | Tampering | client-side clipboard handler | low | accept | The handler only reads a value already present in the document and writes it to the clipboard; it performs no navigation, no request, and no markup insertion |
</threat_model>
