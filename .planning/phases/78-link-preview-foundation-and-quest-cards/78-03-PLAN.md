<objective>
Make the quest Details page require a login explicitly, and rewrite the one regression test that deliberately breaks as a result.

Today the page has no login requirement at all. An anonymous caller gets nothing only because the fail-closed group query filter returns zero rows and the action then answers 404 — an accident, not a boundary. The rest of this phase sets group context from a verified signature, and the moment it does, that accidental protection disappears. Closing it here, before the preview route exists, means the gap is never open.

Purpose: turn an accidental 404 into an explicit login boundary before anything in this phase can exploit the difference.
Output: the Details GET action carries its own login requirement, and the regression suite pins the redirect.

Decisions implemented (see 78-CONTEXT.md): D-09
</objective>
