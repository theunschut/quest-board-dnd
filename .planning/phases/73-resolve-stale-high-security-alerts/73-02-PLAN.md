<phase_ground_rules>
No code, no build, no test suite. `dotnet build` and `dotnet test` prove nothing here and are not part of this plan's verification. Every check is a state assertion.

Windows/PowerShell quoting is a live risk in this plan and not a hypothetical (RESEARCH.md Pitfall 3). `gh api ... -f dismissed_comment="..."` with an apostrophe in the text can be mangled by PowerShell's own quote parsing before `gh` ever sees it, producing a 200 OK with a silently truncated comment permanently attached to a public alert. Every PATCH body therefore goes through a JSON file and `--input`. The drafted comments also avoid apostrophes and double quotes entirely — cheaper than fighting the quoting.

GraphQL and API calls use the real repo name `theunschut/quest-board-dnd`.
