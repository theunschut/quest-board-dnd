<objective>
First half of the operator handover. Get the hosted proof the workstation cannot produce (the
real-SQL atomicity test and the CI lint and network jobs), have the operator create the GitHub-side
gates, then cut and approve the first attested release.

Purpose: everything that must be true on GitHub's side before the server can pull anything, and
the one guarantee (D-07) that needs a real SQL Server.
Output: a green hosted CI run with the SQL tests executed, the deploy environment and tag
ruleset in place, and a published, attested release vX.Y.Z (the version is the operator's choice).

Executor rules for this plan:
- the executor never pushes, merges, tags or changes repository settings itself; those are
  operator actions;
- if a CI job fails, the executor fixes the cause in the repository on the milestone branch,
  commits, and returns to the same checkpoint asking the operator to push again;
- no production host is touched in this plan.
</objective>
