version and tag checks, the HTTP fetch helper, secret-free outcome mail, the outcome decision for

pure functions with row-by-row tests means the orchestration in plan 06 only wires them together.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| /etc/questboard/deploy.conf -> root installer | A file on disk becomes variables in a root process |
