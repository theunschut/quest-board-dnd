<objective>
Render entries from a board whose Events or Quests page is switched off as plain text on linked boards' calendars, using the same inert markup that non-members already get. Past entries from such a board can still fall inside a month someone views. D-08 guarantees nothing from today onward exists there.

Purpose: D-07 says links into a switched-off page disappear. The CONTEXT left linked calendars to discretion (inert text or the redirect), and the inert branch is safer: it reuses markup that already exists and avoids a cross-board session switch that only ends in a refusal.

Output: `LinkedBoard.DisabledPages`, `LinkedEventEntry.CanOpen`, `LinkedQuestEntry.CanOpen`, the service flag, the three view sites, and tests.
</objective>

<recorded_choices>
1. **Inert, not redirect (discretion).** A linked entry links only when the viewer is a member of the owning board and that board offers the entry's page (Events for events, Quests for quests). Otherwise it uses the existing non-member markup unchanged.
2. **A new flag, not an overloaded one.** `CanOpen` is added beside `ViewerIsMember` rather than folding page availability into membership, so `ViewerIsMember` keeps its meaning for any other reader.
3. **No new query.** The owning board's mask rides on the set read that already selects from `Groups`.
</recorded_choices>
