<objective>
Build the save-time rules for a board's page switches and home page as a Domain service, with the two cross-board event counts it needs. The service takes the board as stored plus what the form posted, and returns the resulting settings or the refusals. The Platform Edit page (plan 06) calls it and saves only when there are no refusals.

Purpose: D-01 and D-15 say the server enforces the type ceiling when saving, not just the form. D-13 keeps the home page from pointing at a switched-off page, and D-08 keeps upcoming events from pointing into a switched-off Events page. Keeping these rules in one service keeps the controller thin and makes them unit-testable on a fake clock.

Output: `IBoardPageSettingsService` with `BoardPageSettingsRequest` and `BoardPageSettingsOutcome` declared beside it, `BoardPageSettingsService`, two count methods on `IEventRepository` (with `UpcomingEventCount` declared beside it) and `EventRepository`, and their tests.
</objective>
