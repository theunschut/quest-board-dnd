<objective>
Hide the character pickers when Characters is off and the DM-profile links when the DM profile is off, while keeping the data already shown (character names, portraits, DM names) as plain text. Back the hidden pickers with a server refusal of crafted character ids.

Purpose: D-07 says pickers for a switched-off feature are hidden, links into a switched-off page disappear, and data already on the page stays. A signup without a character is already valid, so nothing else in the signup flow changes.

Output: the character refusal in `QuestController`, the gated controls in both Quest Details twins and both Players twins, and `BoardPageCharacterLinksTests`.
</objective>
