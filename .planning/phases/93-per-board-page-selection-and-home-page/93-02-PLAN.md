<objective>
Put the server gate on the Calendar, Events, Series, Quest, Quest Log, admin quest-list and Move controllers. After this plan, a typed URL or crafted request to any of those pages while it is switched off redirects to the board's home with a toast, for every role.

Purpose: the server-side guard has to stand behind every hidden menu item (the project rule reinforced after Phase 52). Plan 01 proved the mechanism on Shop. This plan gates exactly the controllers that plans 07, 08 and 09 edit next, so those plans keep a single dependency. Plan 12 gates the remaining pages (Shop management, Players, the DM profile, Characters, Contacts) in wave 3 and then adds the closed-list coverage test, once every attribute is in place.

Output: `[BoardPage]` placed across 7 controllers and `BoardPageGateMatrixTests`.
</objective>
