## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| board membership → feed contents | The boundary every fact in this suite exists to patrol. It is crossed deliberately by an explicit filter bypass, so the only thing standing between a member and another board's data is a predicate and a re-check |
| test harness → shared application factory | This plan adds a logging provider to a factory every other integration suite shares; a careless change here breaks unrelated suites |
| application → log sink | Proven at runtime here rather than only by source inspection, because a structured state value can carry an address that a message-template grep would never see |
