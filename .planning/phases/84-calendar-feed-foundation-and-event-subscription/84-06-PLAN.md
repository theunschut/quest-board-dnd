<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser form POST → `AccountController` | Authenticated but the request body is untrusted; a subscription id in the body is an attacker-chosen integer |
| NuGet registry → build output | A new third-party dependency enters the container image and the request path; the automated legitimacy check does not cover this ecosystem |
| server-generated markup → Razor output | The code renderer's output is written into a page as markup rather than as escaped text |
| configuration → published address | The absolute address handed to a reader must be correct forever; a wrong host publishes an address that never works and cannot be corrected on devices that already stored it |
