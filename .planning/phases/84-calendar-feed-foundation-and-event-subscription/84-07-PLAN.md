**Empty state**, rendered when the collection is empty: a centred `text-center py-5` block with `<i class="fas fa-rss fa-3x text-muted mb-3"></i>`, an `h4` reading `No calendar subscriptions yet`, and a muted paragraph carrying the copywriting contract's empty-state body verbatim — the sentence explaining that this gets the schedule onto a phone's own calendar app, that the address acts like a password, that anyone holding it can see the member's events, dates and times, that it never expires on its own, and that nothing is generated until Add Subscription is pressed. Use `readonly` and never `disabled`: a disabled input cannot be focused, selected or copied from with the keyboard, and the whole point of the field is that the member can select the address by hand when the clipboard path is unavailable.
