Inherited unchanged from the foundation spec § "Spacing Scale" (xs 4, sm 8, md 16, lg 24, xl 32, 2xl 48, 3xl 64) and its touch-target and width exceptions. Content spacing uses those tokens only; markup uses Bootstrap's `0 1 2 3 4 5` steps (0, 4, 8, 16, 24, 48), never an arbitrary inline value.
