Add the regression guard that would have caught this gap before a human had to.

tests added during the validation audit (`CalendarButtonStyleTests`, `PlatformAreaLayoutTests`)
cover the calendar and the Platform area only. GSD's own `ui.safety-gate` cannot help either:

a spec that exists — it reported `hasUiFiles: false` on every run of this phase, including the
waves that added two stylesheets and four Razor views. So the guard has to be a project test.

Purpose: make each of the three defects plan 77-11 fixes into a failing test if it returns.
Output: a new mobile-user-agent style-conformance test class, and a validation map that records it.
</objective>
