<objective>
Build the bounded aggregate read path and the in-memory aggregation that the availability
overview page is made of: one EF Core query returning the next N live upcoming events with
their signups and member names, and one domain service method that turns that into a member
axis, per-row counts, and a five-state cell matrix.

Purpose: this is the whole technical risk of Phase 77 concentrated in one place — the N+1
constraint (D-28), the tenant boundary (D-26), the cancelled-occurrence exclusion (D-12), the
date-only lower bound (D-11), and the answered-vs-default distinction (D-04) all live here.
Everything downstream is presentation over what this plan returns.

Output: five new domain types, one new options class, one new repository method, one new
service method, and a unit-test class covering all five cell states and all three counts.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
