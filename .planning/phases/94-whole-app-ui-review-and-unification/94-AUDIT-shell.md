# Phase 94 Audit: Shell, layouts, footers, toasts and backdrop (`A-shell`)

Audit of the five layouts, both footers, the shared toast partial and the notice-board backdrop, done in senior-frontend Critic mode against the frozen baseline (port 8001, commit `b6770322`). It feeds the index file (`94-AUDIT.md`), the operator questions at direction sign-off and the Foundation work of this phase.

## Scope

- **Files audited:** `Views/Shared/_Layout.cshtml`, `_Layout.Mobile.cshtml`, `_Layout.GroupPicker.cshtml`, `Areas/Platform/Views/Shared/_Layout.Platform.cshtml`, `_Layout.Platform.Mobile.cshtml`, `Views/Shared/_Footer.cshtml`, `_Footer.Mobile.cshtml`, `_Toasts.cshtml`, and the shell rules in `site.css`, `mobile.css` and `modern-card.css`. This report covers the shell only; page content is in the six area reports.
- **Evidence base:** the BEFORE record of plan 94-02 (`$QBR/before/report.json`: contrast, interactive inventory and focus probe per page), plus read-only live probes written for this audit under `$QBR/audit/shell/` and run against the frozen baseline on port 8001 (`probe-nav.mjs` navbar geometry per width and role, landmarks and names; `probe-layouts.mjs` structure of each layout under its real User-Agent; `probe-focus.mjs` settled focus rings; `probe-toast.mjs` toasts injected into the live DOM only, nothing saved; `probe-collapse.mjs` the collapsed bar; `shell-contrast.mjs` the contrast maths with `contrast.mjs`). `$QBR` is `~/qb-ui-review/phase-94`. Screenshots are never committed; they are cited by scratch path.
- **Captures added for this audit (scratch):** `/quests` at 992 and 1200 px as Player (`$QBR/audit/shell/shots/quests-992/quests.png`, `quests-1200/quests.png`) and as Dungeon Master (`dm-quests-1200/quests.png`, `dm-quests-1200/top.png`), the Admin user list at the same widths (`adminusers-992`, `adminusers-1200`; it lists accounts, so view locally only), the collapsed bar opened at 800 px (`collapsed-open-800.png`) and the injected toasts (`toasts-desktop.png`, `toasts-mobile.png`).
- **Evidence limit that matters:** the BEFORE focus probe samples a focus indicator at the instant of the Tab press, while the nav links and brand carry `transition: all 0.3s` on `outline-color`, `box-shadow` and `background`; it therefore saw a cream outline that is not the settled state. The settled values quoted below come from `probe-focus.mjs`, which waits 500 ms after each Tab.
- **Baseline against branch:** the frozen baseline still loads Bootstrap, Font Awesome and Cinzel from CDNs; the working branch already self-hosts them (plan 94-11), so request-level findings (A-shell-022) are stated for the baseline and the CDN items that remain on the branch (the Font Awesome v4 shim stylesheet and jQuery) are named.
- **Severity key:** S1 text hidden, unreadable or a control unreachable; S2 visibly wrong or fails the AA bar; S3 inconsistency with the system; S4 polish. Contrast uses the bars of the accessibility contract (4.5:1 text, 3:1 large text and non-text), composited over the reference boards (`B-med`, `B-99`, `B-max` `#794317`).
- **Area phase column:** `Foundation (94)` for every shell finding: the layouts, footers, toasts and backdrop belong to this phase's foundation work, not to an area phase.
- **Fixtures:** none needed. The shell is audited as Player, Dungeon Master, Admin and SuperAdmin on the Audit Board and signed out; no member name, email or user-entered text is quoted.
