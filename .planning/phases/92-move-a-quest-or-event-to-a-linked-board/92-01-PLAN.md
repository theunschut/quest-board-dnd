<objective>
Prove the cross-board write end to end for a quest before anything is built on top of it. A super admin's confirm POST reads the linked set fresh, loads the quest under the source board's filter, moves it to the other board in one tracked save, and lands on the source Quest Board with a toast. The quest's feed revision rises through the existing stamper.

Purpose: the risky architecture of this phase is the write itself — query filters that hide data once `GroupId` changes, the single unit of work (D-20), the store-owned feed revision (D-18) and the server-side policy and set checks (D-01, D-02). The tracer proves all of it on one quest. Plan 03 adds the domain preview, the change-detector stamp and the eligibility rule on this path, so every later plan builds on one preview contract. Plans 04–09 add the page, the people rules, events, mail and the Details controls on the contracts created here and in plan 03.

Output: the `QuestBoard.Domain/Models/BoardMove` contracts, `IQuestMoveService`/`QuestMoveService`, `IQuestMoveRepository`/`QuestMoveRepository`, `MoveController` (quest POST), the shared `BoardMoveSeed` test helper and the tracer's end-to-end proof.
</objective>

2. `QuestMoveService` (internal, in `QuestBoard.Domain/Services`). Its primary constructor takes `IQuestRepository questRepository`, `IActiveGroupContext activeGroupContext`, `ILinkedBoardSetRepository linkedBoardSetRepository`, `IQuestMoveRepository moveRepository` and `ILogger<QuestMoveService> logger`. `MoveAsync` works in this order:
   1. When `activeGroupContext.ActiveGroupId` is null, return `NotFound`. Do not call `RequireActiveGroupId`, which throws.
   2. Load the snapshot with `questRepository.GetQuestWithDetailsAsync(questId)`. It is AsNoTracking and scoped to the source board, so null means `NotFound`.
   3. Read `linkedBoardSetRepository.GetLinkedBoardsForViewerAsync(sourceGroupId, actorUserId)` fresh. When `Boards` is empty, return `NoLinkedBoards` (per D-02 and D-13).
   4. Set `target = Boards.FirstOrDefault(b => b.Id == targetBoardId)`. A null target means `TargetNotLinked`. The source board is never in `Boards`, so a posted source id is refused by the same check.
   5. Read the source name from `GetBoardAsync(sourceGroupId)?.Name`.
   6. Build the tracer plan. `KeptSignupIds` holds every signup id on the snapshot. `DroppedSignupIds`, `PromotedSignupIds` and `FollowUpQuestIdsToUnlink` are empty, and `ClearOriginalLink` is false. Plan 05 replaces this with the membership, chain and waitlist rules on the same record.
   7. Call `moveRepository.ApplyAsync(plan)` inside a try block. Rethrow `OperationCanceledException`. For any other exception, log an error that carries only the quest id and board ids, and return `Failed`.
   8. On `Moved`, write exactly one `logger.LogInformation` with the message template "Moved quest {QuestId} from board {SourceGroupId} to board {TargetGroupId} by user {ActorUserId}: kept {Kept}, dropped {Dropped}, promoted {Promoted}, links cut {LinksCut}" (per D-19). It carries ids and counts only.
   9. Return a `QuestMovePreview` populated with `EntryId`, `EntryTitle`, `SourceGroupId`, `SourceBoardName`, `LinkedBoards`, `Target`, `TargetBoardType = linked.SetBoardType`, `KeptCount`, `Quest`, `DmName` (`quest.DungeonMaster?.Name ??
