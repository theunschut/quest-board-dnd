<objective>
Give the super admin the Linked Boards page on the desktop Platform area, end to end, on top of Plan 01's schema and repository: the domain service that enforces the same-type and at-most-one rules server-side (D-01, D-02), and the `SuperAdminOnly` controller and view that create, rename, add, remove and delete (D-05). Purpose: every calendar change later in this phase reads "which boards are linked to the active board" from what this page stores. Without a real way to create a set, nothing downstream can be proved end to end, and the rules have to live in the service so a hand-posted form cannot mix board types or put a board in two sets.
Output: `LinkedBoardSetService` and its outcome types, `LinkedBoardsController`, desktop `Index.cshtml`, service unit tests and the Platform integration suite.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → LinkedBoardsController | Posted set ids, board ids, names and board type are untrusted, even from a super admin's own form |
| LinkedBoardsController → LinkedBoardSetService | The service is the only place link rules are enforced; the picker is a convenience |
| stored names → Razor/JS | Board and set names are stored text later rendered in HTML and inside confirm() handlers |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-91-01 | Elevation of privilege | LinkedBoardsController (all actions) | high | mitigate | Class-level `[Authorize(Policy = "SuperAdminOnly")]`; integration deny matrix for Admin/DM/Player on GET and POST |
| T-91-02 | Tampering | LinkedBoardSetService.AddBoardAsync | high | mitigate | Server compares board.BoardType to the set's stored BoardType and refuses a board with any LinkedBoardSetId; facts post hand-picked ids directly |
| T-91-03 | Tampering (IDOR) | RemoveBoard / Rename / Delete posts | medium | mitigate | Existence re-checked; RemoveBoard requires board.LinkedBoardSetId == posted set id (NotInSet otherwise); SuperAdmin-only |
| T-91-04 | Tampering (CSRF) | All POST actions | medium | mitigate | `[ValidateAntiForgeryToken]` on every POST; `AntiForgeryTokenCoverageTests` reflection sweep |
| T-91-05 | Tampering (stored XSS) | Index.cshtml names in HTML and confirm() | medium | mitigate | Razor encoding everywhere, no `Html.Raw`; confirm text via `Json.Serialize` (JS-escaped) then HTML-encoded; `O'Brien` fact |
| T-91-07 | Repudiation | Concurrent super-admin edits | low | accept | Last write wins on one column; super-admin-only page with a handful of sets (RESEARCH Pattern 3) |
</threat_model>
