<objective>
Make one board apply one rule for DM-only sessions on every calendar (D-20, D-19). `/calendar` on both layouts and the Quest Details calendar now hide a `DungeonMasterSession` quest from a viewer who is not DungeonMaster or Admin on the board. A SuperAdmin counts as Admin, which mirrors the quest board's existing `GetQuestsWithSignupsForRoleAsync` rule.

Purpose: D-20 closes a gap on the board's own calendar and is a precondition for the linked reads and overlay (Plans 04 and 05), which must apply exactly the same rule to linked boards (D-19). This is the only change unlinked boards see in this phase, and it is deliberate.
Output: `GetQuestsForCalendarAsync(bool isAdminOrDm, …)` through repository, service and both callers, and an integration matrix.
</objective>
