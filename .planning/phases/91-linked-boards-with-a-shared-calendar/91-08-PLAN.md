<objective>
Bring linked boards to the phone agenda (D-11). `Calendar/Index.Mobile.cshtml` builds its own list from `GetCalendarDays()` and does not use the shared partial. It now includes linked-only days, lists linked rows after the board's own entries, keeps the board name visible as text, links only for members, strikes through cancelled linked events, and states "Also showing: …" under the month bar (D-14, D-15, D-16, D-06, D-08, D-10, D-20).

Purpose: project rule (both layouts), and the decision itself names the mobile agenda as a separate change. Without it, a phone user would book over a linked board's evening.
Output: the mobile view changes, mobile CSS and a mobile-UA integration suite.
</objective>
