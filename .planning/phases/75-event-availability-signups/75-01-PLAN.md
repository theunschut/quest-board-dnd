## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Domain/Service caller → `IEventSignupRepository` | `eventId` and `userId` arrive as plain integers; the repository cannot see the HTTP principal and must not assume the caller validated them |
| `QuestBoardContext` global query filter → `DbSet.Add` | The filter constrains reads only; an insert crosses out of its protection entirely |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-75-01 | Elevation of Privilege | `EventSignupRepository.SetAvailabilityAsync` / `WithdrawAsync` | high | mitigate | Both methods locate the target row by the `(eventId, userId)` pair the caller passed and never by a row id, so there is no identifier a request could supply that selects another member's row. | T-75-04 | Information Disclosure | Insert path in `SetAvailabilityAsync` (cross-board write) | high | mitigate | Task 2 requires an `AnyAsync` existence probe against the filtered `DbContext.Events` before any insert, throwing `ArgumentException` when the event is not on the active board.
