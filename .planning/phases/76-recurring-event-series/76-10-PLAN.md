<objective>
Make the cancelled state visible everywhere an event is rendered, and surface the rolling window's health
where a DM already looks every day.

Purpose: two of the phase's named risks land here. A cancelled session that simply vanishes from the
calendar is indistinguishable from a bug — the same reasoning that already forbids a blank time slot. And
the rolling window's failure mode is silence: the calendar quietly runs dry at the horizon with no error
anyone sees, so the horizon check has to appear on the page a DM opens constantly rather than on the page
they only visit once something is already suspected.
Output: the cancelled chip and agenda modifiers, the Legend row, and the DM-gated horizon banner.
</objective>
