## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| player names (user content) -> confirm text | names cross from Razor into script |
| browser -> Delete and RemovePlayerSignup endpoints | destructive fetches carrying the antiforgery header |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-95-29 | Tampering | player name interpolated into a script string | medium | mitigate | the name moves to a Razor-encoded `data-player-name` attribute read as text; no string is evaluated; the inline handlers that embedded it are deleted |
| T-95-30 | Tampering | availability status written with innerHTML | low | mitigate | status built from elements and text nodes or class swaps; the guard and the SUMMARY grep confirm no innerHTML assignment |
| T-95-31 | Spoofing | delete and remove fetches | medium | mitigate | same endpoints, verb and `RequestVerificationToken` header as today, the token from a Razor-encoded meta; server-side antiforgery and DM/Admin authorisation unchanged |
</threat_model>
